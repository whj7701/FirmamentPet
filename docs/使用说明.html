FirmamentPet 使用说明

一个会自己走动、会说话、能自己决定动作的桌面宠物。支持从网上下载形象、接入你自己的大模型 API。

一、安装与启动

  1. 把 FirmamentPet.exe 和 default_skins 文件夹放在同一个目录（缺一不可）；
  2. 双击 FirmamentPet.exe 即可运行，无需安装；
  3. 首次启动会把 default_skins 里的 9 个自带形象复制到：

%APPDATA%\FirmamentPet\skins\

之后新增的形象也都放在这里。

系统要求：Windows 10 / 11（64 位）。本程序是 Windows 专用，不能直接在 Linux / macOS 上运行。

发行包内文件：

文件 作用
FirmamentPet.exe 主程序
default_skins\ 9 个自带形象，首次启动自动安装
使用说明.html 本说明（浏览器打开，排版最好）
使用说明.txt / .md 纯文本 / 源文件
清理旧托盘缓存.cmd 从旧版升级后，清掉通知区里的旧名字残留（见第六节）
firmamentpet.ico 图标源文件

想开机自启

右键桌宠 → 智能 → 开机自启，勾上即可；取消勾选就关闭。
程序会把当前 exe 的完整路径写进
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run，
换成别的目录/版本后重新勾选一次即可。

也可以手动：把 exe 的快捷方式放进
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup（Win+R 输入 shell:startup 打开）。
懒得动手就让 AI 帮你弄：对它说「帮我把 FirmamentPet 设置成开机自启」。

二、基本操作

本版本没有托盘图标，全部功能都在桌宠的右键菜单里（右键点桌宠即可）。

操作 效果
单击 打招呼 / 说一句话
双击 播放「大招」或跳一下
拖拽 抓起来扔出去，会物理弹跳几下再站稳
右键 打开功能菜单
菜单 → 喂食 好感度 +1、饱食度 +1
菜单 → 状态 查看好感度 / 饱食度

菜单主要结构：

💎 VIP 高级看盘版 ▸   切换监控指数 / 涨跌幅周期 / 股票面板
外观                桌宠大小缩放 / 窗口始终置顶 / 切换形象…
伙伴                再叫一只伙伴 / 喂食 / 状态
行为                移动方式（固定·沿边·乱走）/ 动作（招手·跳·开心·生气·发呆·工作·坐下·睡觉）
智能                AI 聊天 / AI 设置 / 主动说话 ▸
❌ 退出桌宠

三、添加形象（重点）

方式一：从链接导入（推荐）

  1. 打开形象站：https://petdex.dev/
  2. 找到喜欢的形象，复制它详情页的链接，例如：

https://petdex.dev/pets/robin-singsong

  1. 右键桌宠 → 切换形象… → 底部 「从链接导入…」
  2. 粘贴链接 → 确定，等几秒（会自动抓图、切片、生成动作）；
  3. 导入完成后在列表里选中它 → 「应用」。

导入需要联网。程序会先访问 petdex.dev，不通时自动改用镜像站。
只支持标准版式的精灵表；不支持的会提示原因。

方式二：安装本地形象包（.zip）

右键 → 切换形象… → 「安装形象包(zip)…」，选择 zip 即可。

管理已有形象

在「切换形象…」窗口里：

  • 顶部 搜索框：按名字 / 简介 / ID 过滤；
  • 最近使用 自动置顶；
  • 右键卡片：重命名… / 打开所在目录 / 删除这个形象…（正在使用中的不能删）。

四、接入自己的 AI（可选）

不配 API 也能用：说话会走本地台词库，动作走本地随机策略。配了之后，它就会"看场合说话"。

配置方法

右键桌宠 → AI 设置（接入自己的 API），填入：

项 说明 例子
接口地址 OpenAI 兼容的 base_url https://apihub.agnes-ai.com/v1
API Key 你自己的密钥 sk-...
模型 模型名 agnes-3.0-flash

保存后写入 %APPDATA%\FirmamentPet\ai_ayaka.json，只存在本机，不会上传。

接上之后能得到什么

  • AI 聊天（菜单 → AI 聊天）：对话框，按当前形象的人设回答；
  • 主动说话（菜单 → 主动说话 ▸）：
  • 开关、现在说一句；
  • 间隔：随机 25–40 分钟 / 15–25 / 45–70 / 每 30 分钟 / 每 1 小时 / 2 小时 / 4 小时 / 自定义…（1–1440 分钟）；
  • 静默时段：23:00–08:00 / 22:00–08:00 / 00:00–09:00 / 不静音；
  • 看见屏幕：开启后会把屏幕截图（缩到 560px）发给你自己的接口，让它知道你正在玩游戏还是写代码；
  • AI 行为（菜单 → 🧠 AI 行为 ▸）：让模型决定"做什么"——坐下、打盹、招手、走过来、换地方……
    带动作台词；每 1–3.5 分钟想一次，累了会放慢。

费用与限流

每次调用都用你自己的额度。程序内置保护：

  • 全局最小请求间隔 20 秒；
  • 同时开多个形象时，只有"主实例"会调 API，其它实例照常走动但不花钱；
  • 接口报错或限流（429）时自动降级：说话用本地台词，动作走本地随机。

五、其他功能

  • 移动方式：固定不动 / 沿屏幕边缘 / 全屏乱走；
  • 体力系统：走久了会累，自己停下歇一会儿，缓过来继续；
  • 情绪互动：点击、拖拽、喂食都有反应和台词；
  • 多开：菜单 →「再叫一只伙伴」，可同时养多只，会互相跟随；
  • 股票面板：VIP 子菜单里开关，显示当日实时涨跌幅（纯展示，不构成投资建议）。

六、请作者喝杯奶茶（打赏）

右键桌宠 → 「请作者喝杯奶茶 ☕」，会弹出说明窗口，里面放了微信 / 支付宝两个收款码。

  • 完全自愿：打赏与不打赏，功能完全一样，没有任何限制；
  • 窗口里的码是静态图片，扫码金额随意；
  • 不想看就点「关闭」，不会影响桌宠的任何行为。

七、高级看盘版（VIP）激活

免费版：可以正常养、互动、换形象、玩游戏 —— 但不显示实时指数（右下角 HUD 不出现，托盘提示「未激活」）。
高级看盘版：显示实时指数 HUD，解锁 A股 / 美股 / BTC 与秒级刷新（2s/5s/10s…）。

激活步骤

  1. 右键桌宠 → 菜单最上方 「🎫 激活高级看盘版（粘贴激活码）」；
  2. 粘贴你的激活码 → 确定；
  3. 提示激活成功后，菜单顶部会显示「已永久激活」。

还没有激活码？

需要高级看盘版激活码的，请前往抖音关注 90314679138 天穹，详情见其置顶视频。

激活状态记录在本机 %APPDATA%\FirmamentPet\，换机器需要重新激活；
同一个激活码与设备指纹绑定，重装系统后可能需要重新申请。

八、常见问题

Q：双击 exe 没反应 / 闪退？
A：确认 default_skins 和 exe 在同一目录；看 %TEMP%\ayaka_crash.log 有没有报错。

Q：通知区还显示旧名字（如「绫华 A股监控桌宠」）？
A：这不是程序里的文字，而是 Windows 为同一个 exe 路径缓存的托盘条目。
双击发行包里的 清理旧托盘缓存.cmd 即可清除：

  • 它只做一件事：删掉
    HKEY_CURRENT_USER\Control Panel\NotifyIconSettings 下与桌宠相关的缓存条目
    （提示文字、图标快照），然后重启一次资源管理器；
  • 不会动你的形象、配置、账号，也不会卸载软件；
  • 从旧版本升级上来的机器，建议运行一次；全新安装的机器不会出现该问题，无需运行。

Q：会不会很占 C 盘？
A：本体约 115 MB，每个形象 3–10 MB（自带形象已压缩）。临时文件会在 1.5 小时后自动清理。

Q：会调用哪些数据？
A：只在你开启「看见屏幕」时截图，且只发给你自己配置的接口；对话记忆存在本机
%APPDATA%\FirmamentPet\brain_memory.json（最多 30 条、7 天过期）。

Q：不开 AI 能用吗？
A：能。所有互动、动作、形象切换都不依赖网络和 API。

九、卸载

  1. 右键桌宠 → 退出桌宠；
  2. 删除程序目录（exe 与 default_skins）；
  3. 删除数据目录 %APPDATA%\FirmamentPet；
  4. 如设过开机自启，删除注册表项
    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run 下的 FirmamentPet。
